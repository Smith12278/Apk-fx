# ForexPro Demo Trading Dashboard

A responsive forex trading dashboard for educational/demo use.

### Included
- Multiple currency pairs
- Simulated live price movement
- Interactive price chart
- Demo BUY/SELL positions
- Lot-size input
- Open-position P/L
- Close trades and demo balance updates
- Trade history
- Mobile-friendly design

### GitHub Pages
Upload the files directly into the repository root (do not upload only the ZIP), then enable GitHub Pages from Settings > Pages using the `main` branch and root folder.

### Important
This application is a simulator. It does not connect to a broker, execute real orders, or provide financial advice.
